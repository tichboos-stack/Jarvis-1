# JARVIS Android — फोन में APK बनाने वाला पूरा प्रोजेक्ट

यह starter JARVIS voice button दबाने के बाद हिंदी में command सुनता है और कुछ सुरक्षित phone actions करता है:
- YouTube खोलो
- Chrome खोलो
- कैमरा खोलो
- Settings खोलो
- Home पर जाओ
- Alarm खोलो
- समय बताओ

## GitHub से APK
1. इस पूरे project को GitHub repository में upload करो।
2. **Actions** खोलो।
3. **Build JARVIS APK** workflow चुनो।
4. **Run workflow** दबाओ।
5. Run पूरा होने पर **Artifacts** में `JARVIS-debug-apk` डाउनलोड करो।
6. ZIP extract करके `app-debug.apk` फोन में install करो।
7. Microphone permission Allow करो और **🎤 JARVIS सुनो** दबाओ।

यह version PIN/Pattern/Password bypass या screen lock हटाने के लिए नहीं है।
